# Newest approved observation for totals

Accepted 15 November 2026. Owner: Obaro Destiny Udurie.

Unofficial aggregates include the newest approved observation per polling unit and election, ordered by server receipt time and then ID. Device capture time is displayed for context and never controls this ordering.

For the same observer, unit and election, a newer approved sheet supersedes the older approved sheet. Other observers' sheets stay available for conflict checks. Old rows and decisions remain in the audit history; published evidence snapshots do not change when new observations arrive.

SQL performs geographic rollups and includes units with no reports. Party rows stay alphabetical and are never used to declare a winner or project a result. Coverage always means the units loaded in this database.

Counting every observer sheet would duplicate votes. Replacing records would hide the evidence trail. Keeping history while selecting one current observation avoids both problems, but approval timing and coverage still limit what the unofficial totals mean.
