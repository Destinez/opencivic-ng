# Manual reference sourcing

Accepted 15 November 2026. Owner: Obaro Destiny Udurie.

A reviewer attaches an image, figures, the original source URL and retrieval time. IReV references must cite an HTTPS URL on the IReV domain. The service does not fetch that URL or harvest a portal. Source labels distinguish IReV, an EC8A copy and fictional sample documents.

A second reviewer verifies the transcription. Hashes identify the uploaded image; provenance records who transcribed and who verified using pseudonyms in public cases and evidence packs.

A bulk reference importer is deferred until the owner confirms reuse terms and a legal review. Public source links do not imply permission to copy, official status or verified accuracy.
